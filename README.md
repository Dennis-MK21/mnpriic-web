# MNPRIIC Club App

Research, Innovation & Invention Club — Mitunguu National Polytechnic.

## Setup
1. Open `index.html` in this repo's editor on GitHub.
2. Find `const firebaseConfig = {...}` near the bottom of the file.
3. Replace the placeholder values with your real Firebase project config.
4. Commit the change.
5. Turn on GitHub Pages: Settings → Pages → Deploy from branch → main → / (root).

Your live app link will appear on that same Pages settings screen after a minute.
